✨ 简介

无界AI是一款基于人工智能的图片生成工具，支持文生图、图生图、图片融合等多种功能。集成多种先进的AI模型，帮助用户快速创作高质量图片。

  • 无限画布 — 自由创作，灵感无限，支持拖拽、缩放、框选生成
  • 多种模型 — 支持 Flux、Imagen、Playground 等优质模型
  • 中文界面 — 全中文操作界面，简单易用
  • 图片融合 — 框选图片，一键融合创作
  • 提示词助手 — 智能提示词推荐，提升创作效率
  • 本地运行 — 无需联网即可使用（需连接扣子平台）

📦 安装步骤
第一步：检查 Node.js

运行 启动无界AI.bat，脚本会自动检测 Node.js 是否已安装。

💡
自动安装：如果检测到未安装，脚本会提示下载并安装 Node.js。Windows 用户请使用管理员权限运行安装程序。
第二步：解压程序包

1. 解压程序压缩包

2. 进入解压后的 无界AI 文件夹

第三步：启动程序

Windows：双击运行 启动无界AI.bat

Mac/Linux：运行终端，进入目录后执行 ./启动无界AI.sh

等待服务启动后，打开浏览器访问 http://localhost:5000

🚀 快速开始

Windows 用户

1. 进入 无界AI 文件夹

2. 双击运行 启动无界AI.bat

3. 等待服务启动完成

4. 打开浏览器访问 http://localhost:5000

5. 开始创作！

Mac / Linux 用户

1. 进入 无界AI 文件夹

2. 打开终端，运行：chmod +x 启动无界AI.sh

3. 运行：./启动无界AI.sh

4. 打开浏览器访问 http://localhost:5000

5. 开始创作！

🎉
成功！看到 "🎊 无界AI 已启动成功！" 提示后，即可在浏览器中使用。
🎨 功能介绍

主界面布局

  • 左侧区域 — 无限画布，支持图片展示、拖拽、缩放、框选生成
  • 右侧区域 — 功能面板，包含模型选择、图片分类、提示词输入等
  • 左下角 — 生成进度显示，实时查看图片生成状态
  • 右下角 — 版本信息

核心功能

  • 文生图 — 输入提示词，选择模型和参数，一键生成图片
  • 图生图 — 上传参考图，结合提示词生成新图片
  • 图片融合 — 框选画布中的图片，进行融合创作
  • 添加到画布 — 将参考图添加到画布中
  • 一键提取关键词 — 分析图片，提取AI生成提示词
  • 提示词助手 — 根据分类自动推荐提示词标签
  • 产品精修 — 对产品图片进行专业精修处理

❓ 常见问题

Q: 程序无法启动怎么办？

A: 请确保已安装 Node.js 18+ 版本，并检查是否有其他程序占用了 5000 端口。

Q: 图片生成失败怎么办？

A: 请检查网络连接是否正常，以及扣子平台服务是否可用。

Q: 如何使用 OpenAI 模型？

A: 选择 GPT Image 2 或 DALL-E 3 模型，然后在 API Key 设置中填入您的 OpenAI API Key。

Q: 进度条显示100%但图片未生成？

A: 这是网络延迟导致的显示问题，图片仍在后台生成中，请稍等片刻。

📌
注意：首次使用建议先测试生成一张简单图片，确认功能正常后再进行正式创作。
