# 无界 AI 未验证项（2026-08-01）

## 阻断原因

云端预览页面可加载前端，但所有关键 `/api/*` 请求命中不存在的 Coze sandbox 实例并返回 `instance_not_found`。扣子项目页同时显示“沙箱连接已断开”，刷新后停在“预览准备中”。

以下项目不是“通过”，而是明确的**未验证/受阻**。

### 2026-08-01 复测环境变化

扣子项目页的沙箱断开提示一度消失，但已登录外部 Chromium 会话中的预览地址在刷新、页面内“重新加载”和直接导航三种方式下均返回 `ERR_BLOCKED_BY_CLIENT`。这是浏览器客户端或扩展层的拦截，不是无界应用的 HTTP 业务响应。

在该浏览器阻塞解除前，所有依赖云端真实 UI 的项目继续保留为“未验证”：实际供应商生成、任务轮询收敛、上传、下载、保存后刷新恢复和视觉质量对比。不得用本地测试或静态审查结果替代真实验证。

### 2026-08-01 新增待验证：普通图像生成终态竞争与积分一致性

- 已存在批注、元素拆解任务的 PostgreSQL 并发测试，但普通图像生成的 `recordImageTaskTerminal()` 未采用同一条件式终态写入接口。
- 需要在独立 PostgreSQL 测试库执行：同一图像任务的成功、取消、失败、超时并发竞争；每个组合均断言最终状态、积分余额和退款流水。
- 在这组真实数据库测试完成前，不能对“普通图像生成取消/失败只退款一次、终态永不反转”给出通过结论。
