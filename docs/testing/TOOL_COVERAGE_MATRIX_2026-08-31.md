- **真实部分通过：** 浏览器真实操作、真实供应商产物与保存结果有证据，但不能扩展为此工具的所有模板、模型、异常和账务通过。

- **完整链路待验：** 尚无覆盖本工具全部验收点的最新证据。不是断言功能必坏，也不是标记通过。
