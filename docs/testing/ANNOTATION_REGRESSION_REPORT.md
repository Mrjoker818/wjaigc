## 安装安全验证

- 包内每个文件记录 SHA-256 和大小。
- 已有文件记录安装前 SHA-256。
- 文本目标使用 LF 规范化内容哈希，兼容 Windows CRLF 检出；二进制目标使用原始字节哈希。
- 新增文件禁止覆盖不同内容。
- 同内容重复安装允许幂等校验。
- Manifest 外文件、路径穿越、禁止范围和缺失文件均会导致校验失败。
- 登录页面、鉴权协议、依赖和云端启动文件不在清单内。
- 共享边界只包含真实 `/api/edit`、`/api/poll-task`、`/api/cancel-task` 和既有任务存储的批注条件分支；普通请求不带批注幂等键时保持原行为。
- `SOURCE_COMMIT.bundle` 随包提供，审核方无需依赖远端临时分支即可解析源码提交。
