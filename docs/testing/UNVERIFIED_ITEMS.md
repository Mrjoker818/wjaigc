## 未验证非功能性场景

| 场景 | 原因 | 建议 |
|------|------|------|
| 高并发压力测试（100+并发用户） | 测试环境资源限制 | 使用 k6/JMeter 单独执行 |
| 长时间稳定性测试（24h+） | 测试周期限制 | 生产环境监控 |
| 弱网环境测试 | 测试环境为本地网络 | 使用 Chrome DevTools 网络节流 |
| 数据库故障恢复 | 生产环境数据库不可中断 | 灾备演练 |
| CDN/静态资源缓存 | 测试环境无CDN | 生产环境验证 |
