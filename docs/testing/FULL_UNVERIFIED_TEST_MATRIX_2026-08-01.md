# 全量未验证项真实测试矩阵（2026-08-01）

## 执行规则

1. 只有真实浏览器中的实际业务结果、可复查截图/日志/网络证据才能记为通过。
2. 已知失败项不在本阶段“修正”；先完整记录，再按 P0 → P1 → P2 统一修复。
3. 对付费模型使用最小测试输入，逐次核对 provider、model、taskId、结果文件、积分与审计记录。
4. 管理员写入型用例因 `AUD-20260801-041` 暂停，待凭据轮换和表单修复后使用隔离账号执行。
5. 原生文件上传与下载需要可注入文件且能捕获下载的浏览器会话；当前外部浏览器能力不足时必须保留“受阻”，不得伪造成功。
