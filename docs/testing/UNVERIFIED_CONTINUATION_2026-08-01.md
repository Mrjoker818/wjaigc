## 本轮扩大确认的缺陷证据

### AUD-20260801-042：后台数据源/审计链路不一致

本轮的运营总览和 API 管理页面补充了同一缺陷的独立证据：

1. 用户侧统计、项目页、资产库可相互验证为 `3 项目 / 54 图片`。
2. 管理员用户管理为 8 人，运营总览仍不能得出总用户、今日生成、积分收支或模型调用量。
3. 运营总览和操作日志仍无法反映同一会话内已发生的项目、生成、失败和取消行为；API 管理的任务监控在手动发布自检后可以正常读取，不能作为本缺陷证据。
4. 控制台仍观察到项目同步请求超时及无效成功响应。这不能被页面仍可加载掩盖；在没有服务端 requestId 和持久化审计记录时，无法证明保存、扣分、退款或任务终态一致。

该问题保持 P1：它阻断管理员对积分、任务、用户操作和生产异常的可靠核对。

### AUD-20260801-044：独立智能对话部署冷启动故障

独立对话的最小文本发送和刷新恢复曾通过，但“新建对话”路由并不稳定：再次进入时页面直接返回 `function_cold_start_timeout`，并暴露 FaaS 启动脚本和端口监听信息。该现象已具备稳定的服务端错误证据，按 P1 登记；完整复现、requestId 和修复前置详见 `BUG_REGISTER_2026-08-01.md`。
