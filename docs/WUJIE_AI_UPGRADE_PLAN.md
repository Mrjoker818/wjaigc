# 无界AI 升级计划分析报告

## 一、现状深度分析

### 1.1 无界AI核心能力梳理

**现有功能架构**：
- **无限画布**：支持拖拽、缩放、多选、框选、Ctrl+Z撤回、分组管理、连线关系可视化
- **图像生成**：支持30+模型（GPT-Image、Flux、SD、Midjourney风格等），画面比例、质量、风格预设
- **视频生成**：支持20+视频模型（可灵V3/V3.5/V3 Omni、Seedance 3.0、Runway Gen-4等），首尾帧、多参考图、延长、音效
- **3D模型**：单图/多图/文生3D，4提供商（混元3D/Meshy/Tripo/Rodin），6视角切换、PBR材质、后处理
- **语言修图**：OpenAI/Gemini双模型，自然语言描述修改图片
- **Agent编排**：工具注册表+Agent循环，支持图像编辑/生成/分析/调色
- **工作流节点**：30+节点类型，DAG拓扑执行，AI自然语言建图，ComfyUI导入
- **矢量化**：vtracer+potrace双引擎，彩色/黑白模式，多级质量预设
- **PSD导出**：Basic/Pro/Studio三模式，背景移除+图层命名+阴影估算
- **品牌系统**：品牌工厂、Logo Skill、品牌电商、字境大师、精修引擎

**技术优势**：
- 多模型聚合能力（30+图像+20+视频+4个3D提供商）
- 无限画布+连线可视化（区别于单一生成工具）
- 工作流节点模式（ComfyUI导入+AI建图）
- 完整的编辑工具链（擦除/蒙版/放大/扩展/去背景/矢量化）
- 本地+云端双模式（IOPaint本地擦除+AI云端生成）

**核心差距**（对比竞品）：
- 缺少真正的Agent自主设计能力（只有工具编排，无自主规划）
- 缺少ChatCanvas对话式画布协作（Lovart核心差异化）
- 缺少预测性交互（模糊意图追问、主动建议）
- 缺少品牌资产系统性沉淀（BrandDNA跨面板注入不完善）
- 缺少多媒体协同生成（音频/音乐独立生成能力）

### 1.3 竞品核心差异化分析

#### Lovart核心差异化
1. **自主设计智能**：从Logo→整个品牌宇宙，无需用户持续指令
2. **多代理协作**：一键生成专业级广告片（旁白+配音+音乐+画面+剪辑）
3. **ChatCanvas**：对话式画布协作，AI作为设计队友
4. **预测性交互**：主动追问、智能建议、需求预测
5. **顶级模型聚合**：GPT-Image-1、Flux Kontext、VEO3、Kling AI、Runway Gen-4

#### 星流AI核心差异化
1. **中文理解强**：自然中文描述直接出图，无需提示词工程
2. **国风优化**：古风人物、国潮插画、水墨风背景、东方审美
3. **智能推荐**：理解语境，给出精准风格建议
4. **色彩控制**：色调/饱和度/亮度精确调节
5. **区域重绘**：局部修改保持整体风格一致

#### 即梦核心差异化
1. **字节自研算法**：Seedream 4.0（Artificial Analysis双榜第一）、Seedance 3.0
2. **音画同步**：口型+环境音+配乐同时生成
3. **智能多帧2.0**：视频片段拼接+锁定编辑
4. **剪映生态**：短视频直接发布、跨端同步
5. **Agent灵感搜索**：一句话搞定插画/海报/Vlog

## 二、升级计划（P0-P2分级）

### P0级：核心差异化补齐（必做）

#### P0-1：ChatCanvas对话式画布协作
**目标**：让AI成为画布上的设计队友，而非单纯的生成工具
**实现**：
- 画布侧边栏对话面板（与ChatPanel分离，专为画布协作）
- AI可"看到"当前画布内容，主动建议下一步操作
- 支持"@图片"引用画布图片进行修改指令
- AI执行结果自动添加到画布，而非独立展示
**技术**：
- 多模态请求注入画布图片URLs
- Agent循环执行生成→添加到画布→再建议
- 预算：2周

#### P0-2：自主设计Agent（Agent-First模式）
**目标**：从工具编排升级为自主设计代理
**实现**：
- Agent接收设计任务（如"为宠物咖啡店设计Logo"），自主拆解→执行→交付
- 多模型协同调度（图像+视频+音频+3D）
- 任务拆解可视化（用户可看到Agent思考过程）
- 支持中途干预（用户可打断修改）
**技术**：
- 扩展agent-engine.ts为自主规划Agent
- 添加任务拆解树（TaskTree）可视化组件
- 预算：3周

#### P0-3：预测性交互系统
**目标**：主动追问模糊需求，智能建议下一步
**实现**：
- 意图分级检测（极度模糊→追问、中等模糊→自动补全）
- 生成后主动建议（图生图/修图/放大/去背景等快捷按钮）
- 对话历史记忆（跨对话保持用户偏好）
**技术**：
- LLM意图分类（prompt中注入分级规则）
- NextSuggestion系统（已在chat-panel中实现，需扩展到画布）
- 预算：1周

#### P0-4：品牌资产系统性沉淀
**目标**：一次设计→多次复用，BrandDNA跨面板注入
**实现**：
- BrandDNA结构化存储（色彩/字体/调性/禁区规则）
- @品牌引用系统（注入到所有生成任务的systemPrompt）
- 品牌模板库（Logo→名片→海报→社媒套图自动延伸）
**技术**：
- 扩展brand-factory-panel为BrandDNA管理中心
- 跨面板注入机制（统一Provider）
- 预算：2周

### P1级：用户体验优化（重要）

**目标**：自然中文描述直接出图，无需提示词工程
**实现**：

**技术**：
- 扩展optimize-prompt API为中文增强版
- 添加国风风格预设
- 预算：1周

#### P1-2：模板系统升级
**目标**：21预设Skill（对标Lovart）
**实现**：
- 图像类5：电商商品套图/分镜故事板/IP角色设计/概念场景设计/漫画连环画
- 设计类10：室内设计/创意海报/PPT演示/杂志封面/服装时尚/名片/书籍封面/贴纸表情/样机展示/App界面
- 品牌类1：Logo与品牌设计
- 编辑类1：营销宣传册
- 社交类1：社交媒体套图
**技术**：
- Skill JSON定义+模板渲染
- 预算：1周

#### P1-3：音频/音乐生成
**目标**：补齐多模态能力
**实现**：
- 文生音乐（描述生成背景音乐）
- 视频配乐（视频生成时同步生成音乐）
- 音效生成（环境音/配音）
**技术**：
- 集成音频生成模型（Suno/Udio/可灵音效）
- 预算：2周

#### P1-4：智能推荐系统
**目标**：理解语境，给出精准风格建议
**实现**：
- 基于用户历史生成偏好推荐
- 基于当前任务类型推荐模型/风格
- 基于参考图推荐相似风格
**技术**：
- 推荐算法（协同过滤+内容相似度）
- 预算：1周

## 四、技术风险评估

| 风险项 | 级别 | 描述 | 缓解方案 |
|--------|------|------|----------|
| 多模态成本 | 高 | Agent自主执行多次生成，成本高 | 预算上限+用户确认机制 |
| Agent复杂性 | 高 | 自主规划Agent逻辑复杂 | 分阶段实现，先工具编排再自主规划 |
| 音频模型 | 中 | 音频生成模型API不稳定 | 多提供商备份 |
| 中文理解 | 中 | 中文提示词优化需要大量测试 | 用户反馈迭代 |

---

## 五、总结

无界AI目前是多模型聚合工具定位，核心优势是无限画布+连线可视化+工作流节点。对标Lovart需要补齐：
1. **Agent自主设计**（从工具→队友）
2. **ChatCanvas协作**（对话式画布交互）
3. **预测性交互**（主动追问+建议）
4. **品牌资产沉淀**（BrandDNA系统）

升级后定位：**AI设计队友**——让AI成为画布上的设计协作者，而非单纯的生成工具。
