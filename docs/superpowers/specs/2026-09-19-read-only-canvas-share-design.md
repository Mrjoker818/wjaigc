# 只读画布分享架构设计

日期：2026-09-19

项目：无界 AI 长期升级目标

阶段：协作能力 → 只读画布分享
状态：设计已获用户批准，待书面规格复核

## 1. 背景与决策

无界已经完成 Asset、AssetVersion、WorkspacePlacement、项目修订和受控媒体恢复等基础能力。当前进入协作能力，但本阶段只做“只读画布分享”，不进入实时多人协作、WebSocket presence 或 Yjs 文档协作。

用户已批准方案 A，固定约束如下：

1. 匿名用户可以持链接查看，但分享页不进入公开索引。
2. 分享链接可撤销、可过期。
3. 默认禁止下载，所有者可以显式开启下载。
4. 数据库只保存分享令牌哈希，不保存可直接访问的原始令牌。
5. 分享绑定精确的项目修订、画布视口和 AssetVersion，不复制可变项目 JSON。
6. 分享媒体通过受控接口读取，不暴露用户、供应商、任务或存储信息。
7. 处理中、未持久化或丢失的媒体阻止创建残缺分享。
8. Simple Chat 分享与画布分享保持独立。

当前仓库证据：

- `main` 当前提交为 `9b6077b7`，与 `origin/main` 一致。
- `origin/stable` 为 `52f7c601`，本阶段不得修改。
- 当前工作树已有 6 个既有 `.superpowers/sdd/` 文档改动；本设计不得覆盖或清理这些改动。
- 当前 AssetVersion 的媒体状态包括 `ready`、`pending-persist`、`missing`、`recovering` 和 `unrecoverable`。
- Canvas 的 Asset Graph 目前直接支持 `canvas-image` 与 `canvas-video` placement；其他画布渲染对象必须通过明确的安全分享适配器纳入，不能静默跳过。
- 项目修订使用 `__asset_graph_projects_revision` 和事务式比较并交换；分享创建必须读取该权威修订，不得由客户端自报版本。

## 2. 目标与非目标

### 2.1 目标

- 让项目所有者从当前画布和项目管理界面创建一个不可变的只读快照链接。
- 让所有者查看、复制、调整策略和撤销自己创建的分享。
- 让匿名查看者在桌面和移动端浏览同一份画布布局、视口和媒体版本。
- 让分享内容与项目后续编辑解耦，确保旧链接不会悄然变成新内容。
- 让撤销、过期、下载策略、媒体归属和媒体可用性都由服务端强制执行。
- 以现有 AssetVersion 和受控媒体能力为唯一媒体事实源，不建立第二套资产状态机。

### 2.2 非目标

- 不支持匿名编辑、评论、批注写入、生成、删除、拖动或重新排列。
- 不实现多人实时同步、在线成员列表、presence、WebSocket 或 Yjs。
- 不把分享内容加入站内搜索、站点地图、推荐流或社交索引。
- 不复用 Simple Chat 的 `wujie_shared_conversations` 表、原始消息 JSON 或分享查看器。
- 不复制完整项目 JSON、提示词、任务记录、供应商配置、模型配置、用户资料或账务信息。
- 不承诺 DRM 级别的防截图、防录屏或防浏览器开发者工具复制。

## 3. 方案比较与选择

### 3.1 方案 A：独立 Canvas Share 资源（采用）

创建独立分享记录和不可变安全投影。记录保存项目修订、视口、AssetVersion 引用、布局变换和下载策略；公开访问只通过不可猜测令牌和分享作用域媒体接口。

优点是边界清晰、可撤销、可过期、可审计，且与当前 AssetVersion/Placement 架构一致。项目继续编辑不会改变旧分享，撤销也可以立即阻止后续媒体访问。

### 3.2 方案 B：实时读取项目的只读视图（拒绝）

每次打开链接都读取当前项目快照。它会使旧链接内容随项目变化，无法证明分享时的项目修订，也会把项目权限和公开访问绑定在一起，违背方案 A 的不可变原则。

### 3.3 方案 C：复用 Simple Chat 分享（拒绝）

现有 Simple Chat 分享保存原始消息 JSON，公开读取路由也按对话内容设计；它不能安全表达画布坐标、AssetVersion、受控媒体、下载策略和项目修订。复用它会产生跨产品面、权限和数据泄露风险。

## 4. 分享资源与数据库契约

### 4.1 分享主记录

建议新增 `wujie_canvas_shares` 表。字段语义如下：

| 字段 | 语义 |
| --- | --- |
| `id` | 管理端使用的内部分享 ID，不作为公开令牌 |
| `owner_id` | 创建者；所有管理操作都以服务端会话身份为准 |
| `project_id` | 所属项目 |
| `project_revision` | 创建时从权威项目修订读取的整数 |
| `token_hash` | 对高熵随机令牌做服务端哈希后的值，唯一索引 |
| `title` | 分享标题的安全文本投影 |
| `status` | `active`、`revoked` 或 `expired` |
| `expires_at` | 到期时间；默认 30 天 |
| `allow_download` | 是否允许公开下载 |
| `viewport` | 创建时的归一化画布视口 |
| `snapshot_digest` | 安全投影的稳定摘要，便于审计和幂等核对 |
| `view_count` | 服务端计数，不返回所有者或查看者身份 |
| `last_viewed_at` | 最近访问时间 |
| `created_at`、`revoked_at` | 生命周期时间 |

建议新增 `wujie_canvas_share_items` 表保存快照项目。每行至少包含：

- `share_id`；
- 内部 `item_id`，作为公开媒体引用的作用域标识；
- `placement_id`、`asset_id`、`asset_version_id`；
- `entity_type`、`asset_kind`；
- 创建时冻结的 `transform` 和安全显示元数据；
- 服务端验证过的 MIME、宽高、字节数、校验和和媒体可用性摘要；
- 稳定排序字段。

表内可以保存服务端读取媒体所需的内部 AssetVersion 关系，但绝不能把这些内部标识直接放进公开响应。分享 item 不得复制可变项目 JSON；它只保存为了重建只读投影所必需的安全字段。

### 4.2 令牌与不可变性

创建时使用至少 32 字节的密码学随机值生成 URL-safe 令牌。原始令牌只在创建响应和前端剪贴板流程中出现；数据库、日志、审计消息和错误响应只允许出现哈希或脱敏摘要。

分享建立后，项目修订、视口和 item 集合不可更新。所有者只能更新分享策略字段：有效期和下载权限。撤销是单向操作；撤销或过期后不能重新激活，必须创建新分享。

## 5. 创建与生命周期流程

### 5.1 创建前置检查

服务端收到创建请求后，忽略客户端提交的 owner、project、revision、AssetVersion 和媒体 URL，按当前登录用户重新解析：

1. 验证用户身份和项目归属。
2. 在事务或等价的修订保护边界内读取权威项目修订。
3. 读取项目当前画布 placement，并核对 owner、project、asset、version、placement 四元归属。
4. 枚举所有应该出现在分享中的可见画布元素；当前 `canvas-image`/`canvas-video` 直接使用 Asset Graph。3D 或其他渲染对象必须有明确的安全预览适配器，否则阻止创建而不是静默丢弃。
5. 要求所有纳入快照的 AssetVersion 为 `ready`，且能通过现有受控存储路径读取；`pending-persist`、`missing`、`recovering`、`unrecoverable` 或临时 `data:`/`blob:` URL 均阻止创建。
6. 读取并归一化当前画布视口；读取失败时使用明确的适应画布视口，不把客户端任意对象写入快照。
7. 生成快照摘要、令牌哈希和 item 记录，在同一事务中写入主记录与 items。
8. 事务成功后才向客户端返回一次性分享 URL。

任何检查失败都不写入半成品主记录或 items，并返回稳定的用户可读错误，例如 `CANVAS_SHARE_MEDIA_NOT_READY`、`CANVAS_SHARE_PROJECT_CONFLICT` 或 `CANVAS_SHARE_UNSUPPORTED_ELEMENT`。

### 5.2 生命周期状态

```text
active -> revoked
active -> expired
```

项目被重命名、继续编辑、删除画布对象或生成新版本，都不会改变已创建的分享。旧分享仍指向原项目修订和原 AssetVersion；若原媒体后来进入不可用状态，查看器显示“内容暂不可用”，不会自动替换为新版本。

## 6. 服务端接口边界

接口名称是设计契约，具体文件拆分在实施计划中确定。

### 6.1 所有者接口

- `POST /api/canvas-shares`：创建快照分享。
- `GET /api/canvas-shares?projectId=...`：只返回当前用户对指定项目有权管理的分享。
- `PATCH /api/canvas-shares/:shareId`：仅更新有效期或下载策略；不得修改快照。
- `POST /api/canvas-shares/:shareId/revoke`：撤销分享，幂等。

所有者接口必须使用当前会话的 `ownerId` 做数据库条件，不能信任请求体中的用户 ID。跨用户或跨项目访问统一返回授权错误，不泄露目标分享是否存在。

### 6.2 公开接口

- `GET /api/public/canvas-shares/:token`：返回经过白名单投影的分享元数据和布局。
- `GET /api/public/canvas-shares/:token/media/:itemId`：读取分享 item 的受控预览媒体。
- `GET /api/public/canvas-shares/:token/media/:itemId/download`：仅在 `allow_download=true` 且分享仍有效时允许下载。

公开接口必须同时检查令牌、状态、到期时间、item 所属分享、快照中的 AssetVersion 关系和媒体可用性。任何失败都不能回退到客户端提交的 URL，也不能远程抓取任意 URL。

公开响应允许的字段仅包括：标题、创建时间或修订标签、归一化视口、item 的作用域引用、媒体种类、MIME、宽高、必要的安全显示文本、布局变换和受控相对媒体地址。

公开响应禁止包含：owner、user、project 内部 ID、placement/asset/version 内部 ID、task、provider、model、prompt、API Key、账务、存储 key、原始供应商 URL 和原始项目 JSON。

媒体接口默认使用内联读取，禁止下载时不生成附件下载动作；下载接口单独执行策略检查。撤销必须在服务端即时阻止新的元数据和媒体请求，避免依赖浏览器缓存。公开页面设置 `X-Robots-Tag: noindex, nofollow, noarchive`，页面 metadata 同样声明不索引。

## 7. 所有者管理界面

### 7.1 入口位置

分享入口位于：

1. 画布项目标题栏或项目菜单；
2. 用户项目管理页的项目行操作；
3. 创建分享弹窗中的“管理已有分享”。

不在单张图片工具栏中放置项目级分享，不在 Simple Chat 或 Workflow 入口中显示本设计的分享动作。

### 7.2 创建弹窗

弹窗必须明确显示：项目名称、将要绑定的修订、纳入的素材数量、媒体检查结果、有效期、下载权限和不可变提示。

默认状态为：下载关闭、有效期 30 天。创建成功后显示完整链接、复制按钮、打开查看器按钮和“前往分享管理”。令牌只在成功响应的短生命周期内传递，不写入项目 JSON、localStorage、操作日志或错误上报。

创建失败时显示靠近触发位置的中文错误和下一步动作：保存冲突要求刷新项目后重试；媒体未准备好要求等待持久化；不支持的元素要求移除或完成安全媒体投影。不得显示供应商原始 JSON。

### 7.3 分享管理列表

列表按创建时间倒序显示，包含状态、修订、素材数量、有效期、下载策略、查看次数和最近访问时间。操作包括复制、打开、修改策略和撤销。

策略修改只能影响未来访问：

- 可以缩短或延长尚未过期的有效期，但不得让已过期记录重新变为有效；
- 可以打开或关闭下载；
- 不允许替换项目修订、视口或 item。

撤销按钮必须二次确认，确认后显示不可恢复说明。撤销完成后列表保留审计记录，不做物理删除。

## 8. 只读查看器交互

### 8.1 页面结构

查看器使用独立的 `SharedCanvasViewer` 只读渲染边界。可以复用当前画布的几何、视口和媒体渲染原语，但不得直接复用会写入项目、启动任务、删除 placement、打开编辑面板或发送聊天的完整编辑器状态机。

页面结构为：

1. 顶部标题栏：分享标题、修订标签、无界品牌和状态提示；
2. 主视口：按快照视口渲染只读画布；
3. 只读工具栏：适应画面、缩小、放大、当前比例、全屏；
4. 媒体预览层：点击媒体后查看更大预览；视频使用浏览器原生播放控制；
5. 下载动作：只有分享策略允许时显示，并且仍由下载接口再次鉴权。

所有拖动和缩放只改变浏览器内存中的视口，不产生保存请求。点击对象可以产生本地焦点和无障碍状态，但不得暴露内部 ID 或编辑工具栏。

### 8.2 失效与异常

- 无效、撤销和过期链接使用统一的“分享不存在或已失效”页面，不区分具体原因。
- 初次加载显示骨架或加载状态，不显示空白画布作为成功状态。
- 单个媒体后来不可用时保留其布局占位，并显示“此内容暂不可用”；其他媒体继续显示。
- 公开接口异常只显示整理后的中文错误和请求追踪标识；不显示数据库、存储路径、供应商响应或完整 URL。
- 查看器不得因为一个媒体失败而自动替换到项目当前版本。

## 9. 移动端行为

### 9.1 手势和视口

- 单指拖动画布；
- 双指缩放；
- 双击适应画面或放大一级；
- 点击媒体打开预览；只读场景不允许拖动对象，因此单指不会触发元素移动；
- 使用现有 Pointer Events 适配方向，避免新增一套触摸状态机；
- 视口坐标、缩放上限和最小缩放由服务端快照与查看器共同限制，项目布局不因设备尺寸改变。

### 9.2 移动工具栏与媒体

在 320px、375px 和 393px 窄视口下使用底部紧凑工具栏，只保留适应画面、缩放、全屏和在授权时显示的下载。按钮点击区不低于 44px，适配安全区和横竖屏。

视频使用 `playsInline`，默认不自动播放声音；模型或特殊媒体只能在拥有安全预览适配器时展示。长按不打开编辑菜单、上下文菜单或项目操作抽屉。

### 9.3 可访问性

所有工具提供中文可访问名称、键盘焦点和 `Escape` 关闭行为。对 `prefers-reduced-motion` 禁用非必要的平移动画和预览过渡；移动端无法执行键盘操作时，所有核心动作仍有触摸等价入口。

## 10. 安全、隐私与运维约束

- 令牌必须高熵、只存哈希；日志、错误、审计和指标不得记录原始令牌。
- 公开接口不接收或解析任意外部媒体 URL，所有媒体关系来自服务端快照。
- 读取媒体前核对分享、item、AssetVersion、项目和存储关系；禁止 IDOR。
- 公开读取和下载按 token/item/IP 做边界限流，限制响应大小、视频 Range 请求和并发连接。
- 默认使用不可共享缓存策略；撤销后不依赖 CDN 或浏览器缓存失效。
- 分享访问日志只记录脱敏分享摘要、状态、结果码、耗时和请求追踪标识，不记录用户私有图片内容。
- 所有者管理接口复用当前认证和 CSRF/CORS 保护，不创建新的匿名写入入口。
- 分享创建、策略更新、撤销和公开访问错误都使用稳定错误码，接入现有操作日志格式。

## 11. 验证门禁

必须按“失败测试 → 最小实现 → 回归门禁 → 云端真实验收”推进；本设计阶段只确定验证要求，不提前运行付费或云端业务操作。

### 11.1 API 与数据库

至少覆盖：

1. 合法项目创建分享，快照含正确项目修订、视口、placement 和 AssetVersion。
2. 项目后续修改不会改变旧分享响应。
3. `pending-persist`、`missing`、`recovering`、`unrecoverable`、临时 URL 或无受控存储目的地会整体阻止创建。
4. 两个用户之间的项目、分享、item、媒体访问全部隔离。
5. 令牌只存哈希，低熵/重复令牌不会导致覆盖或越权。
6. 撤销立即阻断公开元数据、预览和下载；过期链接同样阻断。
7. 下载关闭时元数据和下载接口均拒绝附件下载；开启后只能下载该分享中的 item。
8. 过期记录不可重新激活，策略修改不改变快照摘要。
9. 重复创建、重复撤销、并发策略更新具有明确的幂等或冲突语义。
10. 公开响应不含项目 JSON、提示词、任务、供应商、模型、用户、API Key、存储 key 或原始 URL。

### 11.2 浏览器与移动端

- Chromium、Firefox、WebKit 验证桌面打开、平移、缩放、全屏、媒体预览、失效态和下载策略。
- 320px、375px、393px 验证单指平移、双指缩放、底栏、安全区、视频内联播放和无横向溢出。
- 验证项目编辑器、Simple Chat、Workflow 的受保护入口没有被分享入口替换、隐藏或改变语义。
- 验证打开分享页不会触发生成、编辑、删除、保存、积分或任何供应商请求。
- 验证 Console、Network、截图、Trace 和逐文件媒体证据可以关联到 exact `main` commit。

### 11.3 云端验收

只有在 GitHub `main`、Coze 运行 Commit、数据库迁移和运行模式精确一致后，才可执行云端验收。云端至少需要：匿名有效链接查看、撤销、过期、默认无下载、显式下载、项目后续修改不影响旧快照、媒体失效提示和窄视口证据。任何无法真实验证的项必须标记“未验证”。

## 12. 实施顺序与发布边界

规格批准后再生成独立实施计划。实施计划必须先建立数据库与投影失败测试，再实现所有者 API、公开读取、受控媒体、桌面查看器、移动交互、浏览器回归、隔离 PostgreSQL 和云端验收。

实现期间不修改 `stable`，不复制 V5.8.8 donor 文件，不改 Simple Chat 分享，不建立第二套 AssetVersion、任务、积分或存储状态机。公开分享默认保持关闭，直到本地、真库、浏览器和云端证据全部达到各自门禁。

## 13. 规格自检

- 占位符：没有未完成的必需决策或空白章节。
- 一致性：快照不可变、项目修订绑定、AssetVersion 权威、受控媒体、撤销/过期和默认禁止下载相互一致。
- 范围：仅覆盖只读画布分享；实时协作、Simple Chat 分享和其他 V5.8.8 未关闭能力未被混入。
- 兼容性：当前 `canvas-image`/`canvas-video` 可直接映射；其他画布对象必须有明确适配器或阻止创建，不会静默丢失内容。
- 隐私：公开白名单投影不包含用户、项目内部标识、供应商、任务、提示词、API Key、账务或存储信息。
- 验证：所有关键结论均要求失败测试、数据库/浏览器证据和 exact commit 云端证据；缺失条件不得写成通过。
