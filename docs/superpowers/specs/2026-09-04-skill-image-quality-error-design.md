# Skill 图像质量参数与错误信息修复规格

状态：用户已确认最小修复边界，实施中。基于main当前源码，禁止修改stable。

## 证据

真实run 6b1b53b7-99ed-43aa-84a7-7fc17737f91c的APImart gpt-image-2请求因quality=1K返回400 invalid_quality。Skill未指定quality，chat-tools.ts自行默认1K。/api/generate已经允许quality缺省，不需要引入新的模型默认目录。

executor向pauseForRetry传入异常，但service未传递异常到暂停事件，UI无法显示具体原因。供应商参数错误被泛化为暂时不可用，妨碍判断和恢复。

## 方案比较

1. 所有模型硬编码medium：仅对部分模型有效，不采用。
2. 删除调用层错误默认值，复用现有精确模型能力校验与可选字段约定：推荐，边界最小。
3. 重写供应商适配与模型目录：影响面过大，不采用。

## 推荐行为

- generate_image未显式收到quality时，不向/api/generate注入该字段；不把1K或任何分辨率值当成通用品质。
- 用户明确选择的合法quality保持原值；分辨率通过现有resolution/尺寸字段表达。必须调查现有调用者是否依赖旧默认，并覆盖Gemini及其他分辨率模型，禁止静默丢弃明确设置。
- 复用精确providerId+modelId能力校验。显式不合法的参数应清晰拒绝，不切换供应商，不偷偷改用另一品质。
- 参数400不标为临时服务故障；保留经过现有脱敏工具处理的错误码、有限长度消息、HTTP状态和本地任务关联，禁止向用户暴露密钥、令牌、完整请求或隐私提示词。
- Skill错误暂停保留可显示的安全错误信息，UI显示失败原因与现有重试操作。保持现有暂停/取消/恢复、执行代次、租约和终态限制。
- 不修改真实账本。暂停无退款不能直接判为退款故障；失败/取消结算使用现有任务边界。
- 本次旧任务是否可安全再次执行，需核对下游已知拒绝与幂等恢复规则后决定，不重复创建父任务或盲目重试。

## 验证

1. 先添加失败回归：Skill未提供quality时不得向gpt-image-2发送1K；显式合法值不变；Gemini分辨率能力不回退。
2. 复现400 invalid_quality通过真实生产函数调用链传到错误分类与Skill暂停展示；测试数据只证明本地契约，不冒充真实供应商成功。
3. 覆盖重复事件、旧代次、失败重试、取消终态和完成步骤保留；已有通过测试不得删除或跳过。
4. 专项、模块、全量测试、类型、Lint、保护门禁、构建后再推main。
5. Coze受控同步后强刷现有Google Chrome；真实验证参数、成品AssetVersion、原图不覆盖及账务，失败保留证据。
