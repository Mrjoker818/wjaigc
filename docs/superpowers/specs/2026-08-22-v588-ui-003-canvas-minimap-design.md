# V588-UI-003 无限画布小地图设计

## 目标

在不替换当前无限画布视口控制器、不改变项目数据和任务链路、不删除任何现有功能入口的前提下，为无限画布增加可选的小地图导航。小地图只显示轻量矩形概览和当前可视区域，支持点击跳转，用于大画布快速定位；它不是第二套画布，也不拥有任何业务状态。

## 已确认方案

采用方案 A：

- 桌面端默认关闭。
- 在底部视图工具簇增加小地图图标，并在命令面板增加“打开/关闭小地图”。
- 用户主动切换后，在当前浏览器记住偏好。
- 移动端和可用画布宽度不足时隐藏，不挤压已有工具栏或右侧面板。

## 方案比较

### 方案 A：按需显示的叶级小地图

父画布持有开关和视口状态，小地图只做投影、显示与点击坐标回传。默认关闭使现有工作区零常态渲染开销，且最符合当前选择性吸收原则。采用此方案。

### 方案 B：桌面端始终显示

导航入口更直观，但会长期占据画布空间，并在右侧面板展开时增加遮挡风险；对小项目没有明显收益，因此不采用。

### 方案 C：节点达到阈值后自动显示

能在复杂项目中主动提示导航，但自动出现会改变用户工作区布局，阈值也容易造成状态跳变。本阶段不增加隐式行为，因此不采用。

## 约束与非目标

- 只修改 `main`，不触碰 `stable@52f7c601ed150769e15d06fb435c6e360e28c9e7`。
- donor `J:\无界云端0820` 保持只读；只吸收投影与点击导航思路，不复制其旧式 `offsetX/offsetY` 控制器接线。
- 当前 `useCanvasViewport` 仍是唯一视口状态源；小地图不得直接操作 DOM transform，不得新增平移或缩放状态。
- 不引入图片缩略图、Canvas/WebGL 二次渲染、网络请求、数据库字段或项目保存字段。
- 不在本项增加视口框拖拽、滚轮缩放、多用户光标、节点编辑或节点模式小地图。
- 不删除、移动或重命名现有底部工具栏按钮；只在现有 `CanvasZoomCluster` 增加一个视图切换按钮。

## 架构与组件边界

新增 `CanvasMinimap` 叶组件，输入为：

- 已归一化的画布矩形列表：`id/x/y/width/height`。
- 当前可用视口：`width/height/zoom/offset`。
- 主题、是否可见、关闭回调和世界坐标跳转回调。

组件内部只包含纯函数：

1. 计算内容矩形与当前可视区域的联合世界边界。
2. 计算保持宽高比、带固定内边距的世界到小地图投影。
3. 投影内容矩形和视口框。
4. 把点击位置反投影为世界坐标并回传。

`InfiniteCanvas` 负责：

- 从现有 `images` 构建几何快照，过滤 processing placeholder、非有限坐标和非正尺寸。
- 使用现有 `canvasSize` 与 `canvasOccupiedRight` 计算真实可用视口；右侧面板占用区不计入可视宽度。
- 使用当前 `viewOffset` 和 `zoom` 构建小地图视口，不读取 donor 状态。
- 点击跳转时调用现有 `setViewOffset`，保持当前缩放不变，并把目标世界点放到可用视口中心。
- 持有开关状态、响应式可用性和用户偏好。

`CanvasZoomCluster` 只接收 `minimapOpen`、`onToggleMinimap` 与可用性，显示 Lucide `Map` 图标及明确 tooltip，不持有业务状态。

## 状态与偏好

- 初始值为关闭；仅在浏览器客户端读取 `localStorage` 键 `wujie.canvas.minimap.open.v1`。
- 只保存布尔型 UI 偏好，不写入项目、用户数据库或版本历史。
- 本地存储不可用、值损坏或读取异常时回退为关闭，不阻断画布加载。
- 当视口宽度小于 `768px`，或扣除右侧占用后可用宽度小于 `560px` 时，小地图不渲染，工具按钮和命令入口不可用；恢复到足够宽度后继续遵循用户偏好。
- 关闭小地图后停止几何投影计算；常态关闭时不遍历图片列表。

## 坐标与导航

画布世界点到屏幕点沿用当前公式：

`screen = world * zoom + viewOffset`

因此当前可视世界范围为：

- `left = -viewOffset.x / zoom`
- `top = -viewOffset.y / zoom`
- `width = usableViewport.width / zoom`
- `height = usableViewport.height / zoom`

小地图边界必须取“有效图片矩形与当前可视世界范围”的联合范围，保证空画布、内容全部在视口外和极端平移时视口框仍可见。投影统一等比缩放，不能拉伸内容。

点击小地图得到世界点后，父画布计算：

- `nextOffset.x = usableViewport.width / 2 - worldX * zoom`
- `nextOffset.y = usableViewport.height / 2 - worldY * zoom`

随后调用 `setViewOffset(nextOffset)`。点击不会选择、移动或修改任何图片，也不会改变缩放值。

## UI 与交互

- 小地图固定在可用画布右下区域，位于底部工具栏上方，并向左避让右侧面板。
- 面板使用当前黑金/黑白主题、紧凑标题、缩放百分比、关闭图标和矩形概览；卡片圆角不超过 `8px`。
- 内容矩形不加载真实图片，只用低成本色块；当前视口使用高对比描边和轻透明填充。
- 小地图根节点使用 `data-popup` 和 `data-canvas-minimap`，点击、滚轮和指针事件不得穿透到主画布。
- 点击地图导航；关闭图标只关闭小地图。`Escape` 不专门劫持，避免与现有画布编辑模式冲突。
- 小地图与命令面板、图层面板和版本历史可并存，但位置不能重叠；右侧面板开关或容器 resize 后位置与投影即时更新。
- 空画布仍显示视口框和“暂无画布内容”提示，点击不会产生 `NaN` 或异常偏移。

## 性能预算

- 关闭状态：不构建矩形数组、不执行投影、不新增事件监听。
- 打开状态：每次图片几何或视口变化只进行一次 `O(n)` 纯几何计算；不得读取图片像素、解码图片或发起请求。
- 100 和 300 个矩形都必须完整投影，不能因主画布虚拟化而遗漏远端内容。
- 300 个矩形的纯投影基准在本地 Node/Vitest 环境中，100 次采样的 p95 不超过 `8ms`；浏览器平移时不得触发 React 无限更新、Console Error 或明显卡顿。
- 组件矩形列表使用稳定 memo，单次平移只更新投影与视口框，不重建项目数据或空间索引。

## 错误处理与安全

- 非有限坐标、非有限尺寸、宽高小于等于零的矩形在父层过滤；纯函数仍必须对退化边界返回有限值。
- `zoom` 非法或小于当前画布最小值时使用当前内核的最小缩放边界，禁止除零。
- `localStorage` 读写错误仅影响偏好记忆，不显示阻断弹窗，也不吞掉其他运行时异常。
- 小地图不接收 URL、提示词、用户隐私图片内容或供应商数据，因此不增加上传、SSRF、鉴权和账务边界。
