## 方案选择

采用现有画布抽屉与远程视觉模型的最小接入。独立外部网站会割裂项目/素材/模型与计费；把本功能先接Yjs会重新引入第七项阻塞，均不选。

功能由三个可独立验证的部分组成：绘图和导出；双阶段远程视觉与安全HTML交付；画布和节点入口。用户已授权最优方案自动执行，不为常规实施重新要求确认。

## 绘图交互

- 底部工具栏“草图转代码”打开独立抽屉；不改现有选择、平移、缩放、删除、撤回处理器。
- 固定逻辑画布1024×768，CSS按可用空间缩放。Pointer Events将位置换算为逻辑坐标；笔迹区使用pointer capture与touch-action:none，抽屉其余区域正常滚动。
- 画笔和橡皮擦；8色：#111827、#ffffff、#ef4444、#f97316、#eab308、#22c55e、#3b82f6、#8b5cf6；3档粗细2/5/10逻辑像素。
- 文档与历史不可变；撤销、重做、清空均可逆，最多50步；新笔迹清除redo分支。退出不删除主画布资产；空草图不提交模型。
- 每张草图最多200笔，每笔最多2048点，边长不超过2048；拒绝非有限、越界坐标、非法颜色/粗细和重复笔迹ID。限制防止历史及请求内存无限增长。
- 导出PNG时从笔迹重放，橡皮擦作用于笔迹，最后置于白色纸张上；PNG下载和模型输入使用同一张草图。

## 远程两阶段与安全输出

1. 已登录用户选择管理员配置的具体providerId+modelId；验证真实视觉能力与权限后冻结该绑定，不隐式换供应商、不接受客户端API密钥。
2. 第一阶段对PNG和用户说明进行视觉分析，输出受校验的布局/控件/文字描述。
3. 第二阶段以同一冻结模型把分析转为受校验的界面树及样式。由服务端白名单编译为HTML，转义所有文字和属性。不能把任意模型字符串通过正则过滤后当作安全HTML。
4. 界面树仅允许静态语义控件和有界布局/排版样式：容器、标题、文本、按钮、标签、输入与分隔；不接受script、事件属性、外部链接、远程资源、rawHTML、表单提交、iframe、对象嵌入或任意CSS字符串。
5. 预览iframe使用空sandbox、不授予same-origin/scripts/navigation等权限；HTML自带限制脚本、网络、表单、插件和框架的CSP。预览与下载使用相同安全HTML，不下载未经校验的原始输出。
6. 使用现有任务/积分的受权威保护路径，服务端生成任务身份；两阶段合为一次逻辑任务，失败/取消只退款一次，迟到结果不能覆盖终态。刷新/重试不发起第二次付费任务。真实供应商运行属于单独验收，mock通过不冒充实测。

实施分层：`generateSketchCode(value, dependencies, context)`仅计算并返回`SketchCodeDraft={analysis,html}`，接收服务端身份与AbortSignal；不扣费、不持久化、不另建任务Map。正式鉴权路由须在解析请求体前拒绝匿名，复用现有任务/积分入口、冻结模型并持久化资产后，才组成`SketchCodeResult={analysis,html,previewAssetId,htmlAssetId}`。计算阶段项目授权是当时的读快照，不授权迟到发布；交付仍须经过原项目/资产及终态权威。两个模型阶段各60秒，忽略取消信号的依赖也不能让迟到结果启动下一阶段；真正停止远程请求需HTTP适配器兑现信号，不以本地Promise拒绝冒充。

正式受理接缝：`prepareSketchCode`完成上述项目/目录验证和PNG完整解码后，返回冻结的input、binding、access读快照及`compute(executionSignal)`闭包；准备阶段不发送供应商请求。后续正式路由仅在准备成功后进入原子扣费，并在已有任务租约下调用compute；入站请求结束与任务取消分别处理。此闭包不是一次执行租约、发布许可或新的任务权威，不得由客户端提交，也不能以其旧access替代发布事务的实时授权。原`generateSketchCode`仍组合prepare与compute，保留既有计算接口。

当前HTTP适配范围只支持管理员目录声明的同步、具备视觉能力的chat-completions模型。两个POST使用同一服务端凭据/端点快照和精确providerId+modelId；不追重定向、不自动补/v1重发、不换模型。必须返回JSON、非空字符串content、finish_reason=stop和精确响应model；缺字段或返回别名明确拒绝，不静默放宽兼容性。外层响应最大1MiB，模型JSON仍256KiB；超限或非JSON头即发起取消并拒绝，不等待清理Promise兑现。供应商错误保留安全的原消息、HTTP状态、请求ID和阶段，服务器密钥脱敏；非法URL配置只抛安全错误。实际验证为本地原生HTTP夹具，不是付费供应商验收。

早期内部受理检查点（仅描述该接缝初次落地；后续正式 API、执行、资产发布及 Token 结算已接入，以[分层验证记录](../../testing/2026-10-09-sketch-to-code-acceptance.md)顶部为准）：`admitSketchTask`在完整prepare之后引用原`createBillableTask`及其同事务`beforeCharge`，不另建任务Map或积分流水。按次模型使用同一管理员价格快照、两次调用合计报价；配置为Token按量计费时明确拒绝，实际usage原子结算接入前不能偷偷改为按次。原始PNG/说明不放入任务公开result；摘要包含类型、版本、项目、PNG、说明和精确模型，重试nonce及当前价格不改变同一语义请求摘要。同nonce重试复用原任务和原价格，核验原冻结访问范围及当前权限，但不再次交出compute闭包。权限锁复用原图谱写门、owner项目revision及用户/项目/文档/授权行，保持到扣费事务提交；并不授予后续资产发布许可。数据库提交结果未知时只报告不可用，不擅自重发或退款。

同一早期检查点的开放条件（不是当前“尚未接入”待办）：此内部接缝当时暂不暴露正式API：执行租约、同步供应商重启后状态不明的安全回收、原子资产发布和授权下载接完前，不开放可扣费入口。正式接入须沿用原取消/终态原子退款策略；不能因未取得HTTP结果就自动再次发送可能已经计费的同步请求。

定价读取使用原系统设置权威的严格读取器和新增按需严格解析：只有成功确认无记录时使用原缺省价，读取/解析失败在扣费前拒绝。先经原任务库查询并验证已有幂等任务，重放不读取新价格、不被新Token定价或定价服务故障阻断；并发首次请求仍由原原子受理最后裁决。初始持久状态为原平台可取消的processing、进度0、标签等待执行，不用原退款合同不识别的queued；租约尚未取得不代表已执行模型。

## 项目交付与节点

- 保存安全HTML与草图PNG为同项目结果版本；显示分析、进度、错误和可重试状态，保留原始草图。
- “添加到画布”通过现有资产/版本与placement入口添加可视化结果卡片和HTML交付引用，不直接覆盖projects JSON、原图或只存localStorage。
- 对已有协作文档项目继续走其原权威入口；第七项未恢复时明确报告不可交付，不降级为legacy写入。普通项目的本功能不依赖WS。
- 新增节点ai-sketch-to-code：图片及说明输入；冻结视觉模型选择；同服务返回安全HTML及同项目预览资产引用；输出/预览/下载能消费，不另建任务状态机。
