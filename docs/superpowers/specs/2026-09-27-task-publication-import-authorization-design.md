# 任务成品采纳的冻结授权校验

本设计细化既有 Task8Cb，不改变总目标。用户已授权常规任务自动选择方案；只在本地 main 工作、不提交、不部署，Pear 排除。

## 选择与边界

采用现有 document-media-import 共同事务的中心授权检查，读取 task-publication 已持久化的权威元组。拒绝仅检查当前编辑资格的方案，因为撤销后重新授权会产生新代次；不新建媒体事务、任务状态机或账务。此段是唯一自动发布的必要依赖，不替代完成事件接入、布局/替换意图冻结、task/output 去重、全部生成入口及 UI 验收。

## 行为合同

- 真实 adoptDocumentTaskResult / HTTP adopt 读取服务端任务发布记录，客户端不能提交 owner、grant、publication 或绕过标记。上传与无任务版本导入不查询该表。
- 第一次授权读取形成仅本次调用使用的快照（包括没有记录）。每次后续授权重新读取并核对同一元组，记录新增、删除或变化不能在进行中的调用中静默升级/降级。只在短数据库事务中读取，不跨媒体 I/O 持锁。
- 有冻结记录时始终核对 task.user_id、task.project_id 与记录 actor/project，登录 actor 必须为任务本人。若目标正是冻结项目，当前 owner、workspace_id=project_id、原 grant_generation、enabled、全局开关和规范文档存在性都必须满足。owner 仍使用代次 0。锁顺序沿任务在项目之前；不调用 prepare/persist 创建句柄，旧同-client句柄 Minor 不扩散。
- 冻结任务导入另一个本人可编辑项目，是显式的独立成品转入，继续按该目标当前权限与可信来源规则验证；它不能改变原冻结记录或为原项目升级旧授权。没有冻结记录的历史任务保留既有手动采纳语义，但缺表/SQL故障绝不视作无记录。
- 准备前、取得幂等锁后、最终共同提交事务、上传重放分支及 COMMIT 确认丢失恢复均使用同一个授权检查。授权变化拒绝；准备后拒绝清理本次未提交文件，COMMIT 已发送但无法确定时保留可能已引用媒体，且不发成功 ACK。
- 同键重放仅返回已有结果，不重新下载、不新增行、不复活已删除摆放；撤权后重新授权仍不能重放原代次。现有跨来源同键摘要冲突保持。
- 任务状态、积分、原结果、原始文件不因共享写入被拒而改变，禁止补扣或退款。没有通过共享发布不等于供应商任务失败。
- 身份、代次、元组权限失败沿 DOCUMENT_FORBIDDEN/403；协作设置关闭/全局关闭保留既有 DOCUMENT_PROJECT_NOT_ENABLED/503、DOCUMENT_DISABLED/503，不合并为403。数据库授权读取失败返回固定 CANVAS_TASK_PUBLICATION_UNAVAILABLE/503，HTTP 不含 SQL、路径、连接字符串或 cause；COMMIT 未确认继续现有未知结果语义。

## 验证

本轮执行只用指定新隔离库；永久测试不硬编码本轮端口/库名，仍通过显式 POSTGRES_TEST_DATABASE_URL 与原 schema helper 接入后续 localhost 隔离库。媒体测试在模块加载前，以明确传入的数据根或系统临时目录为base，mkdtemp唯一子目录后设置WUJIE_DATA_DIR并断言；不读取产品默认根。清理只针对校验过的自身子目录，恢复原环境；不能让旧套件从自带隔离变成依赖本轮专用helper。

使用全新 localhost 测试库和模块导入前绑定的数据目录，执行全迁移、真实 createBillableTask 冻结与真实采纳。先复现 grant1 创建 → revoke/grant3 → 原采纳竟成功的行为 RED，再覆盖原代次成功、准备中代次变化、重放、删除后重放、真实提交后丢 ACK 及随后再授权、owner、非冻结历史任务和另目标显式导入。所有数据库及文件副作用直接断言；最终受影响完整矩阵与独立规范/质量审查。云端和自动完成投影保持未验证。
