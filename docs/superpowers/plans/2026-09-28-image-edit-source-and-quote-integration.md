  2. 报价身份由服务端签名，绑定 actor、规范请求摘要、`creditOp`、分项金额、选定的执行 pair、完整价格配置摘要与短有效期；不包含 API 密钥。提交重新鉴权与复验来源、配置、模型授权，先核身份和总额，再建任务/扣费；不匹配或过期返回重报价错误且账本/供应商零变化。同键已持久化任务优先返回原报价/任务，不受后续配置变动或短期身份过期影响。
