# 已有剧本制作短剧

在短剧工作台选择“已有剧本”，粘贴正文或上传 UTF-8 TXT、DOCX。先核对分集、场次、角色、台词数量和解析提示，再点击“确认创建短剧”。解析和预览不会调用生成模型。

1. 在“剧本”中校对正文和分场。原始导入文本另行保留。正文修改后先预览重新解析，确认受影响场次再应用。未变场次的人工摘要和人物选择保留；移除场次转入归档，历史镜头不参加当前成片。
2. 在“设定”中完善角色、场景、道具、参考图与角色声音。锁定参考图后，后续镜头使用同一身份参考。删除角色不会删除原文或原始台词标记。
3. 在顶部选择“编剧与分镜模型”，列表显示后台授权的供应商和模型。明确选择失效时不会自动换供应商。分镜读取对应场次原文，并检查台词覆盖；过长台词需拆镜，不能静默截断。
4. 在“镜头”中选择视频、图像模型并检查模型允许的时长。内容、参考或声音变化后，旧产物保留并提示更新；当前成片使用匹配当前输入的产物。
5. “一键成片”先估算剩余工作。报价绑定内容、模型及声音配置；制作期间暂时锁定编辑。“停止后续制作”阻止新步骤，已经提交的供应商任务另按原回执核对。
6. 页面重开后可使用“恢复原回执”，查询原任务并继续读取、保存产物。生成、产物回读、文件保存分别记录。未知提交或查询超时不会自动发起新的付费生成；本地退款也不等于供应商停止了工作。
7. 在“成片”检查旧版提示、字幕、配音、音乐及剪辑后再渲染。导出可选当前集，或整项目的“选用素材 / 含历史素材”。整项目包包含引用清单；缺失文件明确标注，不完整包不会作为完整项目恢复。历史图片与已移除场次也可保留。

兼容原有项目与单集制作包。TXT/DOCX 上传上限 5 MiB，导入文本上限 100,000 字符；完整制作包浏览器打包/展开总上限 256 MiB，媒体单文件上限 48 MiB。超出限制时请分集或拆分素材。

本功能在现有无界架构中独立实现，保留原身份、模型授权、积分、素材归属和保存版本校验，不包含其他开源短剧项目的源码、提示词或素材。
