### 已修复的兼容缺陷

旧版浏览器可能持有 `wujie_toolbar_order` 与 `wujie_toolbar_hidden`。此前新增工具可能没有出现在旧排序中，同时仍被旧隐藏集合遮蔽，而且自定义弹窗无法重新勾选它们。

主线提交 `3b24d6f` 已新增迁移逻辑：

- 把默认图片工具补回旧排序的正确位置；
- 仅保留用户对旧排序中已有工具的显式隐藏；
- 自动恢复旧配置从未认识的新增工具；
- 迁移后将完整配置回写浏览器存储。

## 不属于功能删除的可见性规则

- 图片工具栏折叠时只显示前 5 项；点击 `+N` 后显示完整图片工具集。
- 视频工具仅在选中视频时显示；选中 3D 素材时仅显示下载。
- 节点模式在云端生产环境会隐藏 JSON 编辑器等开发工具；工作流节点、执行、保存和 AI 建图仍保留。
- 未更新的本地或云端构建不会获得 GitHub `main` 的新增入口。部署后必须刷新构建，而不仅是刷新浏览器页面。
